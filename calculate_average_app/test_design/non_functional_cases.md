# Нефункциональные тест кейсы

## Производительность (Performance)

Требования из описания:

| Объем данных      | Максимальное время выполнения |
| ----------------- | ----------------------------- |
| ≤ 10 000 строк    | ≤ 1 секунда                   |
| ≤ 100 000 строк   | ≤ 5 секунд                    |
| ≤ 1 000 000 строк | ≤ 20 секунд                   |

### TC-NFP-01: Выполнение на 10 000 строк

**Предусловие:** Сгенерирован файл `transactions_10k.csv` с 10 000 строками корректных данных.  
**Шаги:** `time ./calculate_averages.sh transactions_10k.csv`  
**Ожидаемый результат:** Скрипт завершается за ≤ 1 секунды. Файл `averages.csv` создан корректно.

### TC-NFP-02: Выполнение на 100 000 строк

**Предусловие:** Сгенерирован файл `transactions_100k.csv` с 100 000 строками корректных данных.  
**Шаги:** `time ./calculate_averages.sh transactions_100k.csv`  
**Ожидаемый результат:** Скрипт завершается за ≤ 5 секунд. Файл `averages.csv` создан корректно.

### TC-NFP-03: Выполнение на 1 000 000 строк

**Предусловие:** Сгенерирован файл `transactions_1M.csv` с 1 000 000 строками корректных данных.  
**Шаги:** `time ./calculate_averages.sh transactions_1M.csv`  
**Ожидаемый результат:** Скрипт завершается за ≤ 20 секунд. Файл `averages.csv` создан корректно.

### TC-NFP-04: Деградация производительности при росте объёма

**Предусловие:** Последовательно запускаем скрипт на 10k, 100k, 1M строках.  
**Шаги:** Зафиксировать время каждого запуска и сравнить с пороговыми значениями.  
**Ожидаемый результат:** Время выполнения растёт линейно (или сублинейно), не превышая пороговых значений ни на одном объёме.

## Использование ресурсов (Resource Usage)

### TC-NFR-01: Потребление памяти на 1 000 000 строк

**Предусловие:** Файл `transactions_1M.csv` готов.  
**Шаги:** Запустить скрипт под `top` / `valgrind` / `/usr/bin/time -v` и зафиксировать пиковое использование памяти.  
**Ожидаемый результат:** Потребление памяти не выходит за разумные пределы (например, ≤ 500 МБ). Скрипт не завершается с ошибкой `OOM`.

### TC-NFR-02: Нагрузка на CPU

**Предусловие:** Файл `transactions_1M.csv` готов.  
**Шаги:** Запустить скрипт и наблюдать загрузку CPU через `top` / `htop`.  
**Ожидаемый результат:** Один процесс `awk` использует не более одного ядра; нет паразитных дочерних процессов, оставшихся после завершения скрипта.

### TC-NFR-03: Место на диске для выходного файла

**Предусловие:** Входной файл с 1 000 000 транзакций, 10 000 уникальных пользователей.  
**Шаги:** Выполнить скрипт и проверить размер `averages.csv`.  
**Ожидаемый результат:** Размер `averages.csv` соответствует количеству уникальных пользователей × средний размер строки; файл не содержит дублирующихся строк.

## Надёжность и устойчивость (Reliability)

### TC-NFR-04: Повторный запуск перезаписывает выходной файл

**Предусловие:** Файл `averages.csv` уже существует с данными предыдущего запуска.  
**Шаги:** Запустить скрипт ещё раз на том же входном файле.  
**Ожидаемый результат:** `averages.csv` полностью перезаписан без дублирования строк из предыдущего запуска.

### TC-NFR-05: Запуск на пустом (только заголовок) файле

**Предусловие:** `transactions.csv` содержит только строку заголовка `user,date,category,amount`.  
**Шаги:** `./calculate_averages.sh transactions.csv`  
**Ожидаемый результат:** Скрипт завершается без ошибки; `averages.csv` содержит только заголовок.

### TC-NFR-06: Поведение при недостатке прав на запись в рабочую директорию

**Предусловие:** Убрать права на запись в директорию запуска (`chmod -w .`).  
**Шаги:** `./calculate_averages.sh transactions.csv`  
**Ожидаемый результат:** Скрипт завершается с понятным сообщением об ошибке (не молча), код возврата ≠ 0.

### TC-NFR-07: Прерывание скрипта сигналом SIGINT (Ctrl+C)

**Предусловие:** Файл `transactions_1M.csv` готов (скрипт будет работать несколько секунд).  
**Шаги:** Запустить скрипт и нажать Ctrl+C на середине выполнения.  
**Ожидаемый результат:** Скрипт корректно завершается; незавершённый `averages.csv` либо удаляется, либо помечается как неполный. Нет зависших дочерних процессов.

## Удобство использования (Usability)

### TC-NFU-01: Запуск без аргументов

**Шаги:** `./calculate_averages.sh`  
**Ожидаемый результат:** Скрипт выводит понятное сообщение об использовании (usage hint) и завершается с кодом ≠ 0.

### TC-NFU-02: Сообщение об успешном завершении

**Предусловие:** Корректный входной файл.  
**Шаги:** `./calculate_averages.sh transactions.csv`  
**Ожидаемый результат:** Скрипт выводит сообщение об успехе с указанием пути к результирующему файлу (`averages.csv`).

### TC-NFU-03: Код возврата при успехе и при ошибке

**Шаги:**  
- Успешный запуск: проверить `echo $?` — ожидается `0`.  
- Запуск с несуществующим файлом: проверить `echo $?` — ожидается `≠ 0`.  
**Ожидаемый результат:** Коды возврата соответствуют соглашению POSIX и позволяют встраивать скрипт в пайплайны (`&&`, `||`).
